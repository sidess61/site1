# Дневник питания — российский онлайн-поиск perek.us

Это **исходный проект Netlify со встроенной Netlify Function**, а не готовый ZIP со статическими HTML-файлами для простого Netlify Drop. **Нельзя просто выложить содержимое папки `public/`**: тогда офлайн-дневник будет работать, но онлайн-поиск не сможет обратиться к perek.us.

## Что изменено

- Поиск во вкладке «Онлайн» обращается к perek.us (российский рынок `market=ru`), а не к перегруженному Open Food Facts.
- Поиск товаров по русскому названию, бренду и штрихкоду EAN-8/EAN-13.
- Пересчёт КБЖУ на порцию, корректное отображение 100 **мл** для напитков и 100 **г** для еды.
- Ссылки «Данные: perek.us» в результатах, карточках и дневнике в соответствии с правилами источника.
- Ключ perek.us хранится **только в переменной сервера Netlify**, не в HTML и не в браузере.
- Личный пароль доступа к серверному поиску вводится на телефоне. Его можно сохранить через уже существующий зашифрованный сейф.
- Онлайн-категории — быстрые примеры поиска, не полный каталог категорий: например, «Молочное» подставляет «молоко». Ручное название ищется по всей базе.
- Полностью сохранены офлайн-база, 71 рецепт, генерация через Gemini, дневник, покупки и ручное сравнение трёх московских магазинов.

## Перед установкой

1. Сохрани резервную копию дневника: «Сегодня» → «ИИ и безопасность» → «Скачать копию».
2. Получи **собственный бесплатный** API-ключ на https://perek.us/developers. В личном кабинете доступно 1 000 запросов/день, но есть другие лимиты (500 разных товаров в поиске/день, 100 карточек и штрихкодов/день, 20 запросов/минуту). Условия проверь на сайте перед использованием.
3. Придумай отдельный, случайный пароль доступа для своего сайта, **минимум 20 символов**, например сгенерируй 32-символьную случайную строку в менеджере паролей. **Это не API-ключ perek.us.** Не отправляй ни один из этих секретов в чат и не записывай в HTML.

## Как развернуть на текущем Netlify-сайте

Для функции требуется деплой **проекта с обработкой серверных функций**. Надёжный путь — подключить GitHub к **тому же существующему сайту**:

1. Распакуй ZIP проекта. Содержимое папок должно выглядеть так:

   ```text
   netlify.toml
   netlify/functions/perek.mjs
   public/index.html
   public/sw.js
   public/manifest.webmanifest
   public/icon-192.png
   public/icon-512.png
   public/prices-moscow.json
   README.md
   ```

2. Загрузи эти файлы с сохранением папок в **свой закрытый репозиторий GitHub**. Секреты не загружай. На телефоне это удобнее делать с Git-клиентом, поддерживающим ZIP; через стандартное веб-окно GitHub загрузка вложенных папок может быть неудобна. На компьютере можно создать репозиторий обычным Git.
3. Netlify → **существующий проект** → **Project configuration → Developer settings → Continuous deployment → Repository → Link repository** → выбери репозиторий. Не создавай новый Netlify-проект: старый адрес нужен для сохранения localStorage и установленного приложения.
4. Netlify → **Project configuration → Environment variables** → добавь:
   - `PEREK_API_KEY` = секретный ключ из perek.us;
   - `PEREK_APP_TOKEN` = придуманный отдельный случайный пароль (20+ символов).

   Переменные должны быть доступны функциям (Functions scope либо All scopes). Их **не нужно** добавлять в `netlify.toml` и в GitHub.
5. Запусти новый деплой/сборку Netlify из GitHub. Убедись, что функция `perek` опубликована в разделе **Functions**. После изменения переменных среды нужен повторный деплой (если значения не применились автоматически).
6. На том же адресе сайта открой «Сегодня» → «Онлайн» → «🔑 Подключение российского поиска». Введи пароль `PEREK_APP_TOKEN` и нажми «Применить». **Не вводи сюда сам `PEREK_API_KEY`.**
7. Для сохранения пароля на устройстве: раскрой «ИИ и безопасность» → «Зашифрованный сейф», задай отдельный пароль от сейфа (10+ символов) и нажми «Зашифровать и сохранить». После перезапуска можно открыть сейф и продолжить работу.
8. Для проверки введи `творог` в «Онлайн» и нажми «Найти». Открой результат, сверь цифры с этикеткой и запиши порцию.

**Важно:** простой загрузкой статического ZIP через Netlify Drop нельзя гарантировать публикацию `netlify/functions/perek.mjs`. Если функция отсутствует — онлайн-поиск честно сообщит об ошибке настройки. Публикация Git-проекта рекомендуема.

## Тесты и границы

- Локально проверены синтаксис JS, серверная функция с подставным ответом, мобильные сценарии (поиск, EAN, вывод источника, запись еды), переходы между вкладками.
- **Не проверены** боевые запросы с пользовательским ключом к perek.us и реальный деплой на твоём Netlify: ключ и доступ к его аккаунту отсутствуют.
- Если API вернёт 429, 404, 503, 401 — будет показано понятное сообщение, а офлайн-продукты продолжат работать.
- Для защиты бесплатного лимита Netlify Function требует второй пароль. Сильный токен защищает от случайных посетителей, но не заменяет полноценную систему авторизации с серверными лимитами.
- perek.us — данные КБЖУ, **не** ценники Пятёрочки, Магнита или Дикси. Для актуальных цен требуется отдельный источник.
- Правила perek.us: https://perek.us/developers. Источник требуется указывать рядом с пищевой ценностью; запрещено скачивать базу целиком.
